# 🍷 DEMO RESTAURANT — Haute Gastronomie & Surrealist Dining

> Премиальный цифровой веб-сайт ресторана высокой кухни в духе сюрреализма. Проект разработан на Next.js 15, React 19, TypeScript, Tailwind CSS и Framer Motion по эталонному дизайну [Magritte](https://magritte.rest/).

---

## ✨ Ключевой функционал

- 🎨 **1:1 Дизайн и атмосфера Magritte**:
  - Кинематографичный Hero-экран с динамическим видео/фоном и векторным логотипом.
  - Журнальная типографика с Google Font `Jost` и крупными акцентными заголовками.
  - Морфинг-шапка с эффектом размытия фона при скролле.
- 🏛️ **Интерактивные разделы**:
  - **Концепция и шеф-повар**: манифест сюрреализма и история шефа.
  - **Слайдер интерьера**: 10 фотографий залов с плавным горизонтальным скроллом.
  - **Выставка вкусов (Меню)**: интерактивный слайдер блюд с всплывающими названиями и модальным окном каталога.
  - **В фокусе новостей**: новостные карточки с фирменными арочными скруглениями фото и двухэтажными датами.
  - **Подарочные сертификаты**: форма онлайн-заказа сертификата.
- 📅 **ReMarked VIP-виджет бронирования**:
  - Всплывающее окно бронирования стола с международной маской телефона, счетчиком персон, интерактивным выбором даты, тайм-слотов и подтверждением с конфетти.

## 🛠️ Стек технологий

- **Framework:** [Next.js 15 (App Router)](https://nextjs.org/)
- **UI Library:** [React 19](https://react.dev/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Smooth Scroll:** [Lenis](https://lenis.darkroom.engineering/)
- **Icons:** [Lucide Icons](https://lucide.dev/)
- **Effects:** [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)

## 🚀 Локальный запуск
